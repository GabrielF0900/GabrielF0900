## Resultados & Métricas

- **Alta Performance:** pipeline capaz de auditar e deduplicar **1 milhão de transações em 0,309 segundos**, alcançando aproximadamente **3,2M operações/s**, utilizando estruturas hash para buscas de complexidade média O(1).

- **Arquitetura Serverless:** CityShield dimensionado para um cenário de **~200M frames/mês** com Kinesis + Rekognition, incluindo modelagem de custos com estimativa de **~80% de economia anual** frente ao cenário on-premises comparado no TCC.

- **Liderança Técnica:** **+20% de produtividade** da equipe após adoção de Kanban e **-30% no tempo de provisionamento** de ambientes com CI/CD automatizado.

- **Agilidade Técnica:** certificações **AWS Certified Cloud Practitioner (CLF-C02)** e **AWS Certified Solutions Architect – Associate (SAA-C03)** conquistadas em **30 dias**.
